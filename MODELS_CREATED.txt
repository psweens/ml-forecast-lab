================================================================================
MULTI-STEP FORECASTING STRATEGY
================================================================================

Approach: Recursive (Autoregressive)
Inherited from: ForecastModel.predict_multi()

Why Recursive?
- Standard approach for time series forecasting
- Allows model to adapt to its own predictions
- More appropriate for longer forecasts
- Outperforms direct multi-output for many use cases

Implementation Details:
  1. Predict one step ahead with current features
  2. Shift lag features right (lag_N ← lag_{N-1}, lag_1 ← prediction)
  3. Update temporal features (hour, day_of_week, etc.)
  4. Repeat for remaining horizon steps

Lag Features:
  - Assumed naming: y_lag_1, y_lag_2, ..., y_lag_N
  - Automatically shifted during recursive prediction
  - New prediction becomes lag_1 for next step

Temporal Features:
  - hour: Incremented by 1 (mod 24)
  - day_of_week: Incremented when hour wraps to 0
  - month, day_of_month, quarter: Preserved

Input/Output Shapes:
  - Input X: (n_samples, n_features)
  - Output: (horizon,) for single sample
  - Output: (n_samples, horizon) for multiple samples

  - Hyperparameters validated against known parameters
  - Raises ValueError for unknown hyperparameters

Serialisation:

  - Metadata restoration with fallback warnings
  - Feature names preserved across serialisation
